# 📊 EURJPY Telegram Bot (Node.js)

Bot ini mengirimkan sinyal trading otomatis untuk pasangan mata uang **EUR/JPY** setiap 5 menit, 
dan dikirim **10 detik sebelum pergantian candle (detik 00)**.  
Dibangun dengan Node.js, Express, dan Yahoo Finance API.

---

## 🚀 Cara Menjalankan di Replit

1. **Import repository GitHub** ini ke Replit
2. Pastikan file `config.json` sudah diisi dengan token bot Telegram dan chat ID kamu.
3. Jalankan perintah:
   ```bash
   npm install
